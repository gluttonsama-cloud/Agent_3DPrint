# 文字精确抠取与实体暗面补全

2026-09-07，开发版已接入桌面工具“精确提取”。

## 使用

1. 在区域列表选中主体，点击“精确提取”。默认文字模式，框选一行文字；水滴等实心对象切换实体模式，每次框一个对象。
2. 选择接收删去像素的背景区域，点击“生成精确预览”。
3. 对照原图、黑白掩膜及差异。绿色表示增加，红色表示删除；可逐处定位、滚轮缩放、平移或切换 100%。勾选待确认位置查看黄色区域。
4. 用“保留笔画 / 排除背景”提示笔修正后重新生成。参数或提示变化会使旧候选失效。
5. 前后 3D 共用相机位置。应用保存为一步编辑，可撤销；取消不改变工程。

实体模式填充外轮廓内部。真正镂空的装饰应使用文字模式，或画排除提示保留孔洞。

## 实现契约

- `relief:refine` IPC 转发本地 Python 常驻模型进程 `action: refine`。输入原 v1 工程、右下端点不包含的框 `[left, top, right, bottom]`、目标/背景区域、模式和全图提示数组（0 无提示，1 保留，2 排除）。
- 文字：原分辨率 ROI + 缓存的全图 BiRefNet 概率 + 局部 Lab 颜色聚类构造 GrabCut 种子；提示为硬约束。没有整行闭运算、整体填洞或默认小组件删除。
- 实体：SAM 框提示获取轮廓并填实内部，GrabCut 在轮廓边缘排除投影，内部核心保留。填补和边缘调整返回为待确认区域，不执行全局对称猜补。
- 仅替换框内目标/背景两种标签。框外、第三方标签、不打印范围不变。返回全图候选、增加、删除、不确定掩膜及每处变化的包围框。
- 工程格式不变，预览/导出读取最终标签；差异颜色不进入导出。复杂差异超过几何预算时引导使用二维差异。
- 保留原图字形；没有 OCR、换字体或生成式补字。

## 验证

- TypeScript/Vite 构建通过，14 个前端单元测试、32 个 Python 测试通过。
- 精确提取真实 GPU 桌面链路和独立交互契约共 2 项通过；原桌面回归 7 项通过，另一个旧 GPU 场景未重复运行。
- 覆盖黑白文字、JPEG、保孔、硬提示、标签锁定、精确差异，以及参数失效、取消、应用、撤销、保存重开。
- 交付导出逐像素校验：累计掩膜之和等于高度，上层包含于下层，导出工程与最终编辑工程相同。
- `scripts/benchmark_refine.py --out <新目录>` 重跑参考检查；`scripts/deliver_refine.py --out <新目录>` 重建自动基线、提示后对照和导出，需要本地 GPU 模型及已有样本文件。

验证对象是本机 Windows 开发版及现有模型环境。旧安装包的模型运行时未更新，本轮未完成新的干净机器离线安装验证或实机打印验收。
