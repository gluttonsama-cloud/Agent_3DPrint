**裁剪后的“自动分色／主体提取”为什么别扭**

你说的“二选一”，更准确地说是“裁剪后的识别方式分叉”。这不只是按钮名称的问题。

1. 自动分色回答“按颜色划分哪些可编辑区域”；主体提取回答“哪些像素属于主体”。它们解决不同问题，可以组合使用。当前主体提取内部也会调用自动分色，界面却要求用户先选一条路线。
2. 用户此时通常只想确定“保留什么、去掉什么、哪里要凸起来”，并不想先学习识别算法。当前页面先呈现识别方式、颜色容差或主体层数，再要求“生成预览”和“应用识别结果”。
3. 两条路线对背景的处理不同：分色路线可以把背景设为非打印区；主体路线默认将背景保留为 0 层。**0 层仍可打印彩色，不等于不打印。** 这会使外观看似相近的操作产生不同输出。
4. 识别页没有“返回裁剪”；取消会结束本次导入，而不是带着当前状态回到上一步。

建议主线：**导入图片 → 按需裁剪 → 确定打印范围 → 划分可编辑区域 → 设置高度 → 检查并输出**。

“确定打印范围”和“划分区域”可以放在同一个工作区：默认生成可编辑预览；把“只保留主体”作为按需工具；始终显示非打印区、仅彩色区、凸起区的区别。高级分色参数折叠，需要调整时再展开。背景去留由用户的输出意图决定，不由识别算法暗中决定。无需为上述每个概念新增一个确认页面。
