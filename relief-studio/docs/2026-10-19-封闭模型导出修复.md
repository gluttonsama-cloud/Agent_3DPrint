# 封闭模型导出修复设计与实施计划

目标：修复当前 OBJ 无封闭底面，以及 STL 只读取区域默认高度的问题，保留倒角、平滑和局部调高后的逐像素结果。

## 方案与边界

共享现有 STL 已验证的像素网格三角化，分别接二进制 STL 和索引 OBJ 写入器。避免另写一套平滑表面、引入重采样或新几何依赖。相比只给旧 OBJ 补底，此方案同时处理侧壁 T 接点；相比引入网格修复库，它不会隐藏原始高度或自动改轮廓。

- STL 接收完整 v2 工程，设计工程可显式指定每层厚度；标定工程沿用 mmByLayer，不允许同时指定统一层厚。旧 v1 调用保留。
- OBJ 增加 solid/surface 模式。现有 API 未指定选项时保留 surface 兼容；桌面导出面板选中 OBJ 时默认 solid，并显示底板与修复选项。
- 封闭模型默认 1 mm 可调矩形底板，高度为“底板＋实际像素高度”。选择零底板时不为零高度像素制造厚度；全零且无底板明确失败。原来的表面查看模式保留原始 Z。
- 只在用户明确选择时修复角点。先将物理高度映射为有序等级，再按等级补连接，避免标定曲线或小于 1 mm 的高度被取整。只修改输出模型，返回改动像素和新增体积，UV 母版及工程不变。
- 封闭 OBJ 使用同一拓扑，按相邻行缓存共享顶点和 UV，避免全模型字典占内存。底板的透明区以白色实体材质显示，UV 图像文件保持原样。
- 表面 OBJ 保留原 200 万面/512 MiB 上限。封闭模型保留 2500 万面上限；封闭 OBJ 写出前精确预估索引和文本上界，限制 1 GiB，不静默降低采样。STL 保留原二进制尺寸上限。
- 取消、失败和已有目标检查继续工作；共享三角化按行检查取消。导出成功不等于任意切片器、设备、RIP、材料或实际打印已经验证。
