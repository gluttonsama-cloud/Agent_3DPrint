## 修复

- 模型 JSONL 管道固定 UTF-8。此前 Windows 本地代码页可能误读 Node 发来的中文工程字段，之后再保存便固化乱码。真实 GPU 回归验证中文工程名和区域名往返不变。
- 打开旧工程时仅恢复已知默认名称的乱码，不对任意客户名称猜测转码。已损坏且无法确定原文的自定义名称需要人工改名。
- 原修整允许零层目标以高层主体为背景，可能将删去像素分配到凸起层；引擎现在拒绝高于目标的背景。界面移除两个独立入口，新自动流程只处理主体掩膜，不改原图、区域高度或追加几何层。

## 算法

BiRefNet 初选后，按连通组件生成局部范围，使用原图颜色和概率引导 GrabCut。相邻行内对象按文字处理，保留小点和已有孔洞。孤立的窄长小组件可自动生成 SAM 框及正提示点，提取内面；已有封闭孔洞不执行实体填充，新增内部需要具有明暗变化，拒绝占满框的底板候选。

最多精修 128 个主要组件和 24 个实体候选，其他像素保留初选。局部无候选保留原结果；CUDA 等运行故障仍明确报错。该规则是自动优化启发式，不等于对任意图像都能判断文字和实体语义。
