新增局部背景证据：对明显亮于背景的有色主体，背景以下的深色投影不能因模型高置信度而锁定为前景；用周围背景重建平滑照明场，排除与光晕颜色接近的假连接。保留/排除硬提示仍优先，黑白文字不套用亮色材质规则，实体暗面继续走完整轮廓处理。

独立的高置信深色组件另外保护，避免邻近金色图案导致黑字误删。混合金块与黑字、纯黑字、文字投影、光效桥、保留提示回归均通过；本轮共 43 个 Python 测试通过，并通过真实 GPU 桌面流程。最后的深色组件保护调整重新执行了原图算法检查。

## 修复

- 模型 JSONL 管道固定 UTF-8。此前 Windows 本地代码页可能误读 Node 发来的中文工程字段，之后再保存便固化乱码。真实 GPU 回归验证中文工程名和区域名往返不变。
- 打开旧工程时仅恢复已知默认名称的乱码，不对任意客户名称猜测转码。已损坏且无法确定原文的自定义名称需要人工改名。
- 原修整允许零层目标以高层主体为背景，可能将删去像素分配到凸起层；引擎现在拒绝高于目标的背景。界面移除两个独立入口，新自动流程只处理主体掩膜，不改原图、区域高度或追加几何层。

## 算法

BiRefNet 初选后，按连通组件生成局部范围，使用原图颜色和概率引导 GrabCut。相邻行内对象按文字处理，保留小点和已有孔洞。孤立的窄长小组件可自动生成 SAM 框及正提示点，提取内面；已有封闭孔洞不执行实体填充，新增内部需要具有明暗变化，拒绝占满框的底板候选。

最多精修 128 个主要组件和 24 个实体候选，其他像素保留初选。局部无候选保留原结果；CUDA 等运行故障仍明确报错。该规则是自动优化启发式，不等于对任意图像都能判断文字和实体语义。

## 主体内分色（2026-09-14）

主体掩膜优化完成后，自动调用 CPU 分色，不再把全部前景固定为一个金色区域。
`segment` 可接收原图尺寸的 `subjectMask`（0/1）及 `subjectLayers`。
只在主体内聚类，原有效范围内的背景保持标签 1、0 层，主体色区使用标签 2 起，
不打印范围保持标签 0。所有主体色区初始使用同一高度；分色不改变轮廓、孔洞或原图 RGB。

自动模式按 Lab 分色后合并色相接近的有色明暗，保留黑、灰、白以及不同色相。
区域色块为区域像素的代表色，原图的渐变和材质反光仍由原图贴图显示。
这是一项颜色启发式，不是材质识别；非常浅的金色高光仍可能形成独立色区，
相近色相的不同颜料也可能合并，可在主编辑器中继续调整。

识别窗口提供主体色区列表，点击查看选中范围，再次点击恢复整个主体。
补选、排除、画笔及撤销后重新分色；失败或取消的分色结果不应用，应用时可重试。
已有工程不自动改写，重新识别后才产生新色区。

回归覆盖多色主体、黑白保留、近似金色明暗合并、微小红色、孔洞、透明与锁定范围，
并逐像素比较主体掩膜和累计导出层数。桌面测试固定模型掩膜、运行真实 Python 分色，
检查色区切换、层数设置和工程保存重开，不以此替代模型精度验收。

## 分色边缘约束

JPEG 的黑金交界处可能包含灰白混合像素，单纯按全图调色板距离分色会把这些
像素分配给远处的白字颜色，设置不同高度后形成细柱。`color_edges.py` 在最终
分区上增加局部约束：颜色明确的像素和同色平坦内区作为种子；不确定像素只能
选择周围 3 像素范围内有种子支持的颜色，无局部支持时保留原标签。
不按连通块面积删除像素，不执行填洞，不修改主体掩膜、透明范围或原图。
此处理同时用于自动分色和主体内分色，最终标签共同供预览和导出读取。

徽标样图裁剪复现中，831 个像素重新分区，白色 1–4 像素组件从 177 个降至 0，
9,993 个明确白色像素全部保留。黑 0 / 金 5 / 白 10 层的实际导出已验证高度图
与累计掩膜一致。对照文件位于 `artifacts/logo-diagnosis/stepped-3d.png` 和
`refined-3d.png`，校验结果位于 `edge-verification.json`。
这些是该样图的局部验证，未将小块数量当成字形完整性的唯一验收标准。

### 近似色与渐变边缘

花卉样图中深浅绿色距离较近，原来的 RGB 32 容差会把混合色当作可靠种子，
而色区平均色无法代表局部渐变。存在 Lab 距离小于 30 的色区时，改用 RGB 6
容差保留明确细节，同时保留同色 3×3 内部种子；模糊边缘比较三像素内最近种子
的实际 Lab 颜色，并加入空间距离惩罚。所有种子均从原始标签生成，避免迭代扩散。
高对比配色继续使用已验证的原规则，不按面积删点、填孔或把深浅绿合并。

花卉样图主体分色重算约 1.25 秒，969 像素重新归类；浅绿 1–4 像素组件
70→6，深绿 26→2。剩余小组件没有假定为噪声全部抹除。主体范围与原图保持一致，
实际导出高度图、累计掩膜与标签高度逐像素一致；黑金徽标与上一版修复标签完全相同。
记录：`artifacts/flower-diagnosis/verification.json`；3D 对照：
`before-stepped-3d.png`、`local-colors-3d.png`。层数为对照用参数，并非读取客户工程。
