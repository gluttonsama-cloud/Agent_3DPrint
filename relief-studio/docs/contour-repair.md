# 轮廓自动修整

区域属性新增“自动修整”。选择目标区域和相邻底层后生成预览，绿色表示补全、
红色表示移除；可查看修整前后 3D。只有“应用修整”提交一次工程编辑，支持撤销。
参数改变会清空旧预览并回到修改位置，避免误用上次结果。

## 当前规则

- 在目标和指定底层两个标签之间调整，其他区域及“不打印”标签 0 锁定。
- 1–3 px 椭圆核闭运算补窄缝、开运算削毛刺；显示对应横向毫米尺寸。
- 保留原有封闭孔洞。若去毛刺导致原有连通笔画断开，恢复这一部分。
- 孤立块默认全部保留，避免删除标点；可明确选择清理不超过 2、4、9、25 像素的小块。
- 左右对称微修默认关闭。开启后以目标区域外接框中心为轴，镜像交并比至少 0.9
  才补轮廓附近的缺口；其余图案跳过。不进行任意轴推断、整体镜像或大面积重绘。
- 保留原图 RGBA 和各区域的层数配置；被调整像素所属区域改变，其实际高度随之改变。
  预览、工程保存与累计分层均使用修整后的同一份标签。

## 验证记录

29 项 Python 测试通过，新增 6 项覆盖补缝、孔洞、标签锁定、原图不变、
细笔画与标点、对称处理及拒绝明显不对称、无效参数、修整后导出的累计层数。
桌面真实算法测试通过：生成预览、取消不修改、3D 显示、参数重置、应用、保存及整步撤销。
构建通过。截图位于 `artifacts/repair-diff.png`、`artifacts/repair-3d.png`。

内置徽标以黑色为底层、半径 1 px、保留碎点、关闭对称：金色新增 0/移除 7 像素，
白字新增 50/移除 175 像素。这些是修改量，不是人工判定正确率。

这版处理局部栅格缺陷；不能从不完整文字中可靠推断缺失字形，也不会补回已标记为
“不打印”的像素。仅有用户提供的 3D 截图，尚未拿到对应工程，未宣称截图每一处问题已修复。
需要更大跨度的补全或局部对称时，应先把目标独立成区，结合源图确认后处理。
