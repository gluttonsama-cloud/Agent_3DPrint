### 必须遵守的数据与协作约定

以下约定已在本计划中完整列出，不需要阅读另一人的计划。

| 项目 | 固定约定 |
|---|---|
| 工程范围 | Windows 桌面，本轮 LOGO／文字／色块；最长边 2048 px，最多 256 层 |
| 图像与蒙版 | 方向校正、裁剪后的原始工作图保留；编辑彩图、区域标签、高度和保护标记同尺寸、同原点 |
| 区域 | 区域 ID 稳定；标签 0＝不打印；非零标签且高度 0＝仍可彩印 |
| 高度 | 逐像素白墨总层数是唯一几何依据；区域层数只作默认值，局部修改后显示“混合高度” |
| 编辑保护 | 每像素位标记：1＝范围保护、2＝颜色保护、4＝高度保护；自动操作遵守相应保护，用户明确手动操作可以修改其目标范围 |
| 擦除 | 标签和高度同时归零，设置范围及高度保护；彩图原始 RGB 不必破坏，输出通过可打印蒙版排除 |
| 补回 | 只在原始工作图有效像素内，从原图恢复颜色，分配到选定区域并使用其默认层数，同时更新保护 |
| 高度归零 | 只减少白墨，保留可打印标签及彩色，不能当成擦除 |
| 原子修改 | 一次笔画／一次算法应用统一提交标签、彩图、高度、保护和区域属性，统一撤销 |
| 异步结果 | 携带工程 sessionId＋revision；提交、撤销、重做、换图均递增 revision；旧结果丢弃 |
| 保存 | v2 单 JSON；运行时 TypedArray，持久化栅格采用带类型的 Base64 小端编码；上限 128 MiB |
| 旧工程 | v1 由区域层数生成高度，不改变原有背景与颜色；首次保存 v2 另存 |
| 撤销 | 变化块历史，预算 64 MiB；大操作应用前核算，单次超预算须允许取消，不静默丢失撤销 |
| 毫米高度 | 未校准默认固定“10 层＝1 mm 设计高度”，写入工程；不随当前最大高度自动改变 |
| 输出 | PNG 无损母版＋客户 JPG 适配；OBJ 用于查看交换，非加工级实体；光油和照片深度留到后续 |

**冻结的能力接口：**

| 接口 | 输入／输出与职责 |
|---|---|
| ProjectSnapshot | 原图／彩图、标签、高度、保护、区域、尺寸、设备配置、sessionId、revision |
| SelectionMask | 与工作图同尺寸的 Uint8 蒙版；不依赖屏幕坐标或 3D 网格 |
| EditPatch | 变化栅格块的前后值＋属性变化；唯一编辑提交入口 |
| HeightOperation | 均高、结构建议、设高、加减、整体缩放、倒角、平滑；返回带版本的候选修改，不自行改工程 |
| RecognitionOperation | 全图／局部范围、保留背景选项、保护策略；返回带版本的候选修改 |
| ExportRequest | 已提交工程快照、设备配置、JPG／PNG 与 OBJ 选项；返回输出目录、清单及检查结果 |

具体 TypeScript 字段、Python 编解码和 IPC 形状由 A 在 D1 前写成唯一协议；D1 通过后不得各自临时增加一套字段。B 负责调用与原子应用，A 负责算法和文件接口。

**共同样例包由 A 提供，B 可直接使用：**

- v1 旧工程；v2 正常工程与损坏文件。
- 小栅格：多颜色、0／3／6／10 层、真实孔洞、零高度彩色区、不打印区和人工保护。
- 2048 px 典型图与碎边压力图。
- 科尔沁 LOGO、京瓷金属图、卫星油菜花图的关键人工检查区。
- 每个样例包含预期高度、可打印范围、白墨层与坐标说明。模型输出不能当作人工真值。

**运行命令：**在 `D:/AAAwork/Agent_3DPrint/relief-studio` 内运行 `npm test`、`npm run test:engine`、`npm run test:e2e`、`npm run build`。先运行本任务相关用例；对接时运行完整链路。

### B 的子代理使用规则与可选并行安排

**默认自己做。** 文档编写、计划复核、普通搜索、简单测试和小修改不派子代理。实现子代理优先使用 Sol 系列，始终选择适合任务的模型系列中当前可用的最新版本，并在调用时显式指定；当前使用 GPT-6.1 Sol（gpt-6.1-sol）。每次派发前核对可用模型，不永久锁定版本号，不因主模型设置而意外继承 Astra。一次最多两个，且必须是已冻结接口、能独立交付、预计至少半天、与本人工作不存在同文件冲突的编码模块。预计并行节省的时间不足以覆盖交接与合并成本，就不派。用户说“不用子代理”时不派。

派之前写明文件所有权、输入、输出、验收测试和交接点。派后子代理不得再派子代理；并告知“你不是独自在仓库中工作，不得回退其他人的改动”。子代理交付代码与测试即可，由你整合主工作台。下面只列可选窗口，并不要求全部开启。

|---|---|---|---|

| B2／B3 | 历史、补丁、App 整合 | 画笔与脏区域绘制辅助可选 | 套索／选区运算可选 |
