# A7 识别回归与大图解码修复（2026-10-04）

## 发现与修复

基于 `d362cea`，分支 `cys/relief-a7-recognition-regression`。

## 已覆盖的实际链路

`tests/recognition-v2.spec.ts` 通过真实 preload → IPC → Python，不替换识别或输出处理器：

- 透明图导入保留字孔；人工擦除、改色和调高在默认重识别后保留。
- 显式覆盖返回真实候选，预览不提交；应用后一次撤销恢复像素及工程属性，旧候选被拒绝。
- 指向不存在的模型目录，不透明图识别明确失败；随后仍可 CPU 调高、保存重开与输出。
- 实际回读 PNG 白墨层重建高度、核对覆盖；JPG 尺寸可读，OBJ 顶点/面、MTL/贴图存在。
- 2048 图右下角 8×8 局部识别新增 63 像素，透明孔保持不打印；诊断使用工作坐标，范围外不变，撤销恢复像素和属性。
- 保存大图后在真实工作台点击打开，验证渲染进程也能解码恢复。

识别回归走透明 alpha 分支，不证明 BiRefNet/SAM 模型质量或模型裁剪回映射。
候选应用部分直接使用生产 EditorStore，属于接口及状态整合回归，不冒充 B 的完整 UI 操作流程。
单次 IPC 编解码/识别/提交计时写入 `artifacts/a7/recognition-2048.json`，不是 B6 的 P95，也不代表拖动性能。

## A7 资源与任务恢复续验（2026-10-04，基于 22ddc76）

分支 `cys/relief-a7-task-lifecycle`。本次继续软件任务，没有等待 B。

复现并修复两处任务生命周期问题：

- 无响应的 height/recognition/import 子进程在用户取消后只写取消标记，原来可能一直占用任务槽直至十分钟超时；现在先合作取消，10 秒宽限后终止。重复取消不会延后截止时间。
- 临时目录删除异常会跳过任务槽释放，使后续任务永久误报忙碌；现在清理增加短暂重试，并在独立 finally 中释放槽。永久清理失败仍报错，不伪装目录已删除。

保存/导出保持合作取消，避免把已经原子提交的文件误报为取消；原全局任务超时边界未变。
两项故障均由测试先复现失败、修复后通过。

本轮验证：

- `npm run test:ipc`：4 项通过，覆盖运行中无响应进程终止、重复取消、临时目录清理、任务槽恢复、保存迟到取消和启动/退出失败。
- `npm test`：53 项通过。
- 源码 Electron 回归：recognition-lifecycle / recognition-v2 / capabilities-v2 共 5 项通过。
- 新 IPC 回归连续三轮识别→立即取消→调高恢复，每轮 `relief-v2-*` 临时目录数为 0。该场景取消可能发生在 spawn 前，运行中无响应进程由专用真实 fixture 子进程测试覆盖。
- `verify_recognition_resources.py` 对真实 CPU 引擎完成 12 个场景：2048 全图/8px 碎块透明图各连续三次、各一次取消及高度恢复、模型缺失及恢复。全部达到预期，任务子进程退出，未观察到残留后代，脚本自己的临时目录全部清理。

最终采样：全图三次进程用时 2.797–3.063 秒，RSS 峰值 412.9–453.1 MiB；碎块三次 2.672–2.719 秒，398.8–403.7 MiB。
取消请求在引擎启动 0.5 秒后发出，返回延迟为 0.219 / 0.235 秒；没有断言请求发生在算法哪个内部阶段。
采样间隔 20 ms，峰值为采样所得，不保证捕获瞬时最高点；前轮测量与 Electron 回归并行，表列为审查修订后单独重跑数据；未控制整机背景负载，不作为标准性能基线或 P95。
每个任务使用独立引擎进程；这些数据不证明长期 UI/GPU 无泄漏，也不是 B6 的画笔/松笔性能验收。

## A7 退出与真实 GPU 取消续验（2026-10-04，基于 c0bc85d）

分支 `cys/relief-a7-shutdown`，包含前述 D1、候选验证、大图解码和生命周期修复的全部提交。

新增 v2 `shutdown()`：停止接收新任务，取消已有计算任务，并等待子进程结束及临时目录清理；已有保存/导出仍按合作取消和真实提交结果收尾。
Electron 从 `before-quit` 改到 `will-quit` 阶段启动清理；用户在未保存提示中选择继续编辑时不会提前停掉任务。完成异步清理后才允许进程退出，重复退出请求不重复启动清理。

验证分层：

- IPC 专用测试 6 项通过；新增启动前退出、运行中退出、重复退出和保存收尾场景，先失败后通过。
- 真实窗口测试：取消关闭后高度请求成功；确认关闭时已有 Python 引擎进程，应用退出后记录的进程消失，v2 临时目录为空。
- 真实 BiRefNet CUDA 取消：RTX 5070 Laptop GPU，Torch 2.7.1+cu128。探针保留真实模型前向计算，仅附加开始/完成标记。最终通过真实 v2 管理器返回 cancelled，用时 7.113 秒；`forwardCompleted=true`，本次属于合作取消，不能宣称实际触发十秒强杀。无响应计算的终止兜底由专用子进程测试另行覆盖。
- 同一管理器取消 GPU 后，CPU 调高任务成功，逐像素验证可打印像素为 11 层、其余为 0；GPU 子进程退出，临时任务目录删除。
- GPU 证据：`artifacts/a7-gpu-ipc-recovery-20261004/verification.json`。这是开发环境 BiRefNet 验证，不包括 SAM、模型效果验收或 GPU 安装包。
