# 手工修整工具简化

2026-10-13。按用户确认的方向，统一入口和名称，保留现有能力。

## 界面约定

- 点选：智能点选、连通选区两个模式。
- 选区：矩形、自由圈选两个形状。
- 修补：补画、擦除两个模式。
- 平移继续作为画布导航，不与修整动作混在一起。
- 同色选区改为“选择整个区域”按钮，选中左侧当前区域的全部像素，支持追加与减去。
- “保留”改为“只留选中部分”，明确会清除当前区域未选中的部分。
- 画布选区默认限制在当前区域，连通点选也遵守此范围；跨区域选取与排除只能通过高级设置中的复选框明确开启。切换工具、全选不自动开启。
- 左侧“选择整个区域”支持明确追加不同区域。已有跨区域选区在关闭设置后保留，但 Delete 只清当前区域；开启时 Delete 排除整个选区。
- 区域属性仍在高级设置中；不改选择、画笔、擦除和工程存储算法。高级设置保持手动展开，方式选择放在画布上方，紧凑窗口保留区域列表空间。

## 中央预览与画布导航重做（2026-10-13）

用户反馈侧栏 3D 太小、平面缩放不顺手、高度参数拥挤后，改为中央“平面编辑 / 对照 / 3D 浮雕”三种视图。对照在宽窗口左右并排，中央不足 700 px 时上下排列；“展开画布”暂时收起两侧面板，适合小屏对照，随时可恢复。独立 3D 占满中央，并提供复位视角。切换视图保留二维选区、手动缩放和平移；适合窗口模式随视口重新适配。

平面画布采用自由平移与实际像素缩放：滚轮围绕鼠标位置缩放，空格拖动或鼠标中键可从图片外的工作区起拖；Shift+滚轮水平移动。Ctrl+0 适合窗口，Ctrl+1 实际大小，Ctrl++ / Ctrl+- 放大缩小。底部显示真实缩放百分比，100% 对应一个图像像素一个 CSS 像素，范围 5%–1600%。导航不提交编辑历史，笔画或轮廓绘制过程中不改变缩放。

高度面板统一间距和按钮尺寸，明确显示作用范围；应用、逐层增减直接可用，均高、结构建议、比例和倒角/平滑收进高级处理。区域高度明细按需展开，移除重复标题与常驻说明。仍保留设计高度未标定提示，算法、设备标定和导出语义不变。

## 轮廓高度建议误判修复（2026-10-13）

用科尔沁真实示例复现：旧建议把原黑色 0 / 金色 5 / 白字 10 层改成黑色 6/10、金色 3/6/10、白字 3/6。原因是字符孔洞参与闭合包含判断，同一色区得到互相矛盾的底面、装饰、细线角色，后遍历的孔洞还会覆盖早先证据。

改为累计区域角色证据，存在冲突的整区保持现高，仍遵守选区、保护位和层数上限。不根据颜色猜真实厚度，不用平滑掩盖误判。界面改称“轮廓层级建议”，明确不识别文字或真实立体结构；无变化时提示保留现有高度，不增加历史步骤。像素轮廓在近距离下的阶梯仍是当前栅格建模的显示特征，本次不宣称已完成曲面重建。

本轮修改了 CPU 高度引擎；下次发布须重建 CPU 引擎，不能继续复用旧冻结引擎。AI 模型未变化。已经应用旧建议的工程需撤销该步骤或恢复原工程；修复不会自动推断并还原用户原始层高。源码开发版重启后使用修正逻辑，公开安装包尚未更新。

验证：构建、9 项高度引擎测试、3 项相关 Electron 用例通过；真实徽标经过实际引擎建议后保存，确认高度、标签、颜色、保护位均不变且撤销不可用，简单明确结构仍可建议，ID 重排不影响冲突保护。只读审查未发现明确 P1/P2。

## 多边形与磁性套索、视图保持（2026-10-13）

“选区”增加多边形套索（P）与磁性套索（M），保留矩形与自由套索。多边形逐点点击；磁性点击起点后沿边缘移动，实时吸附附近颜色或透明度边界，点击可固定锚点。Enter、双击或点击起点闭合，Backspace 回退，Esc 取消草稿并保留已有选区，Shift 追加、Alt 减选。弱边缘保持手绘位置，不宣称自动理解整张图的主体。超过 12000 个磁性轨迹点时明确取消草稿并提示分段添加，避免提交截断轮廓。

## 套索交互修正（2026-10-13）

根据实际使用反馈，磁性套索从逐点吸附改为固定点间连续边缘寻路，保留实时待确认尾段，按累计描边距离自动添加固定点；修复小轮廓绕回起点后路径缩没、固定点再次吸附漂移和右下图像边界漏选。平坦区域保留直线待确认段；弱边缘或复杂纹理仍需手动固定点，不宣称与 Photoshop 算法等同。

多边形与磁性套索拖动时捕获指针，画布禁止浏览器文字选择。绘制时提供“完成选区 / 取消绘制”，继续支持 Enter、双击、点击起点闭合。Delete、Backspace、Ctrl+Z 回退草稿，不删除工程像素；绘制中可滚轮缩放、空格或中键平移，保留固定点。

磁性路径预计算局部边缘代价，无边缘区域跳过图搜索，并限制自动固定点的图像距离，减少缩小大图描边时的开销。真实科尔沁徽标使用按住拖动描牛头，确认选区并保存清除结果，检查仅修改牛头范围内的黑色区域；截图 artifacts/workbench/magnetic-logo-draft.png 和 magnetic-logo-confirmed.png。本次仍为源码开发版修正，安装包未更新。
