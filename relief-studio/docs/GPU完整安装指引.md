# Relief Studio 完整安装指引

适用版本：0.4.2-d2.4，Windows 10/11 x64。

## 正常安装：只下载一个安装程序

1. 打开 [d2.4 发布页](https://github.com/gluttonsama-cloud/Agent_3DPrint/releases/tag/relief-studio-v0.4.2-d2.4)，下载 `Relief-Studio-Complete-Setup-0.4.2-d2.4.exe`。
2. 运行安装程序，使用默认的当前用户安装路径即可。安装程序未签名；仅在确认文件来自上述发布页并核对校验值后继续安装。
3. 安装程序会检测 NVIDIA 显卡及驱动。
   - 驱动可用：出现“是否启用 AI 主体识别”，点击“是”。
   - 驱动缺失或不兼容：出现“是否自动安装 NVIDIA 驱动及 AI 模型”，点击“是”。Windows 可能显示管理员授权，请核对程序后授权。
   - 点击“否”：正常安装手工编辑版。之后重新运行同一个安装程序，选择“是”即可添加模型。
4. 程序自动下载模型与 GPU 运行时，总下载量约 **2.61 GB**，校验 SHA256 后解压并做真实 CUDA 运算检查。用户不用安装 Python、PyTorch 或 CUDA Toolkit，也不用手工合并分卷。
5. 完成后启动 Relief Studio，导入图案，在识别窗口中选择主体提取，生成预览后检查并应用。需要局部调整时使用点击补选、点击排除或画笔。

如果驱动安装要求重启，程序不会自动重启电脑。请保存其他工作并重启，再次运行同一个安装程序完成模型设置。

## 硬件、网络与空间

- 自动主体识别需要支持当前 CUDA 运行时的 NVIDIA 显卡。已验证 RTX 5070 Laptop GPU；其他型号尚未逐一实机验证。显存不足会导致识别失败，手工编辑与导出仍可使用。
- 驱动检查采用 NVIDIA CUDA 12.8 的 Windows 基线 **570.65**。驱动版本号通过不等于 GPU 功能通过，安装完成前还会运行 CUDA 运算检查。[NVIDIA 说明](https://docs.nvidia.com/cuda/archive/12.8.0/cuda-toolkit-release-notes/index.html)
- 自动下载需要能访问 GitHub Release 和其附件下载服务。
- 模型安装后约占 **5.8 GB**。联网安装时，模型所在盘建议至少有 **10 GB** 可用空间，以容纳下载、解压和校验的临时文件。
- 模型存放在 `%LOCALAPPDATA%\ReliefStudio\model-runtime`，与软件安装目录分开，重新安装或更新软件不会清掉模型。
- 程序及模型均在本机运行，识别时不需要将图片上传到云端。

## 驱动自动安装的范围

选择“是”后，安装程序通过 Windows Update 查找与本机硬件匹配的 NVIDIA 显示驱动，只处理显卡驱动，不安装其他系统更新。

部分电脑的驱动由厂商管理，或者 Windows Update 没有提供满足要求的版本。这种情况下程序会说明自动安装未完成。请从 [NVIDIA 官方驱动页面](https://www.nvidia.com/drivers/) 或电脑厂商支持页面安装适合本机的驱动，重启后重新运行安装程序。程序不会强行安装其他型号的驱动。

静默安装默认只安装软件，不会自动下载模型或更改显卡驱动。使用 `/S /GPU=1` 可显式添加模型，但无人值守模式遇到驱动不兼容时会停止 GPU 设置，保留手工编辑功能。

静默 GPU 设置失败时，安装程序返回退出码 `1`；需要重启时返回 `3010`。软件主体会保留，不能仅凭软件已经出现就判断 GPU 配套安装成功。

## 安装后如何检查

打开图案，进入识别窗口。如果“主体提取”可以生成预览，并且“点击补选”能够调整区域，说明两种模型都可调用。生成预览后先检查文字孔洞、细线、暗面和图案外背景，再应用结果。

保存工程后重新打开，确认修改仍保留。二维编辑、撤销、保存和导出使用内置 CPU 引擎；安装 GPU 配套不会要求这些操作依赖显卡。

模型版本标记只用于确定版本，安装程序还会检查完整文件清单和 CUDA 运行状态。文件被删除或损坏时，重新运行安装程序并启用 AI，可重新下载修复；替换失败会恢复旧运行时。

## 网络较差时的离线安装

正常联网安装不需要手工下载以下分卷。若要给离线电脑安装，在有网络的电脑从同一发布页下载：

- `Relief-Studio-Complete-Setup-0.4.2-d2.4.exe`
- `relief-gpu-runtime-d2.4.7z.001`
- `relief-gpu-runtime-d2.4.7z.002`

将三个文件放在同一文件夹，不改文件名、不自行解压。运行安装程序，选择启用 AI。程序会优先使用旁边的分卷，自动校验和解压。离线电脑仍需事先安装合适的 NVIDIA 驱动；如果驱动缺失，Windows Update 自动安装需要联网。

## 常见问题

| 现象 | 处理方法 |
|---|---|
| 未检测到 NVIDIA 显卡 | 先使用手工编辑。AMD/Intel 显卡尚未接入本模型运行时 |
| 驱动不兼容或要求重启 | 完成驱动安装并重启，再次运行完整安装程序 |
| 下载或校验失败 | 检查 GitHub 访问与磁盘空间，重新运行；也可使用同目录离线分卷 |
| 提示磁盘空间不足 | 释放模型所在盘空间后重试；失败下载的临时目录会清理 |
| 之前选择了“否” | 再次运行同一安装程序，选择启用 AI |
| 识别漏掉尖端或细线 | 使用点击补选或画笔修边；自动结果仍需人工复核 |
| 模型提示显存不足 | 关闭占用显存的软件，减小输入图或使用手工编辑 |

本版本属于预发布候选。模型可运行不代表图像质量、客户 RIP 适配、封闭实体或设备试印已验收。
