## 本轮改动

1. 修复智能点选的范围掩膜始终限制当前区域的问题。显式开启跨区域后，智能点选也可选取其他区域；Shift 追加、Alt 减去仍仅改变选区。
2. 默认允许智能点选、连通选取、矩形和套索选到原图非透明的未打印部分。清除后可以直接重新圈回，不必进入隐藏设置或逐笔补画。
3. 新增“补入当前区域”。默认只补选区内未打印部分，不抢占其他区域；显式跨区域时允许覆盖邻区。原图透明像素不能补成打印区域。重复增补且没有实际变化时，不新增编辑历史并给出提示。
4. “清除”改为“清除选中部分”，与 Delete 共用范围规则。关闭跨区域仅清除当前区域，开启后清除整个选区内的打印像素。“只留选中部分”仍只修整当前区域。
5. 范围开关从折叠的高级区移到常用面板，增加范围和覆盖说明；“追加选区（不改变打印内容）”与“补入当前区域”分开命名。增补结果显示目标区域、变化像素数及可撤销提示；按钮可换行，适配 960px 窗口。

原有跨区域补画／擦除保留。原图颜色恢复、透明区防护、人工保护位、目标区域默认高度、撤销历史、保存格式来自既有 legacy-adapter / EditorStore，本轮复用并验证，不作为新增算法成果。补回采用目标区域默认层数，不宣称恢复清除前每个像素的独立手绘高度；需要精确还原清除前状态应使用撤销。

### 发现并处理的测试环境问题

- 仓库锁文件的 npmmirror 下载被云端网络策略返回 403。依赖在临时目录从官方 npm 源按原锁定版本和完整性值安装，未修改仓库锁文件。Electron 下载使用环境提供的代理。
- 云端为 Debian Linux，开发引擎入口写死 `.venv/Scripts/python.exe`。测试环境建立该入口到虚拟环境 Python 的符号链接，使用 Xorg dummy 显示；产品 Windows 入口未改动。
- 第一轮 Electron 由于 Python 入口尚未准备好，6 项失败、5 项通过。准备完成后同组重新运行，11 项全部通过。
- Python 首轮 133/134 通过；`test_logo_auto_three_zero_heights` 比较 PNG 压缩字节，在未修改 main 的隔离副本同样失败。改成比较完整解码像素，不放宽图像内容正确性；重跑 134/134 通过。分区算法未改动。
