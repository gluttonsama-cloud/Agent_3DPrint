# 0.4.1 手动修整与 STL

在 `handable` 分支增加，保留 0.4.0 的自动分色、主体提取、细化和原有工程格式。

## 手动修整

1. 左侧选中要修整的区域。这里的“当前层”指左侧当前区域，区域的堆叠层数保持不变。
2. 智能点选：点击需要的部分，按原图颜色、相邻连通关系和透明边界选取，只在当前层内生效。
   调整“选取宽容度”可重新计算本次点选；数值小更严格，大则选入更多近似颜色。
3. 框选适合清除边缘长条；圈选可沿图案大致拖一圈，松开闭合。默认“自动贴边”会向附近
   原图颜色与透明度边缘调整，并抑制轮廓抖动；需要精确手画时可关闭。
4. 点“清除”删除当前层圈内部分；点“保留”删除当前层圈外部分。两者都不改变其他区域。
   选取范围本身不修改工程，实际删除可撤销。无有效选区时禁用操作，避免误清空整层。

Shift 追加选区、Alt 减选，或在选取方式中选择；Esc / Ctrl+D / 取消选区可取消，
包括尚未完成的智能计算。切层时自动清空选区；计算放在后台 Worker，主界面可继续响应。
较复杂的重新分配、补画、擦除、颜色和层数操作仍可从“更多工具”和“层属性与更多设置”进入。

智能选择依据图像边缘，不识别文字语义。阴影、反光或很低对比度的边缘可能仍需要框选补修；
斜向仅通过角点相接的细线、极淡的透明边缘和单个孤立像素也可能选取不完整。
蓝色区域先预览，确认后再清除或保留。

## STL

点顶部“导出 STL”，填每层厚度（示例值 0.1 mm）。高度 = 区域堆叠层数 × 每层厚度。
勾选矩形底板时再加底板厚度；底板覆盖整个矩形画幅。取消底板后，0 层与清除区域不生成实体，
因此图案可能包含多个独立实体。STL 只保存形状，不包含颜色。

导出使用原像素网格和工程毫米宽高，与三维预览的视觉夸张比例无关。输出二进制 STL，
含顶面、底面和侧壁，检查浮点精度与三角面数量。坐标 X 向右、Y 向原图上方、Z 向上。
原图上边位于模型 Y 最大处。最长边仍为工程上限 2048 px，复杂模型可能产生较大的文件。
超过 2500 万三角面会提示失败，保留原有目标文件；桌面计算仍有 120 秒超时限制。

只有对角相接的像素可能形成不可用的实体连接。默认发现此情况时停止导出并在弹窗提示。
可在“模型修复选项”勾选“修复像素角点连接”后重试：仅在导出副本中补齐小连接，
可能增加少量材料，完成后报告修复像素数；工程标签、PNG 分层和源图保持不变。
取消保存或生成失败不会覆盖已有文件；成功后才替换用户在保存对话框确认的目标。

算法接口新增 `{"action":"stl","project":...,"options":{"layerHeightMm":0.1,
"baseThicknessMm":1,"repairDiagonalContacts":false}}`。
输出目录包含 `model.stl` 和 `mesh-info.json`（三角面数、毫米尺寸、修复像素数和增加体积）。
桌面版只保存用户选择的 `.stl` 文件。
