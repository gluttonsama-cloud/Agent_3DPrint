## 完成内容

1. **高度算法整合与毫米倒角**：接入此前在 `b3cfc37` 分支的倒角、平滑修复，先用旧算法复现六项失败。等高颜色交界、选区与保护边界不再产生假沟；倒角向真实邻接低面过渡，保留已有梯度。补修与台面相连的一像素宽长细尾、窄桥，以及圆形/菱形帽尖的针状退化。
2. **物理宽度**：默认毫米倒角，按工程尺寸分别换算 X/Y 像素间距；保留像素兼容模式。毫米距离采用精确欧氏计算，等间距采用 OpenCV 精确 L2 快速路径。倒角宽度与平滑次数独立设置，不再共用“处理半径”。512/1024/2048 的固定 64 mm 图案均验证了 2 mm 宽度，另验证非方像素及距离量化误差。
3. **重新识别保护**：从原始图分析，正式 v2 候选保留人工范围、改色、混合高度和命名；默认仅处理当前选区，允许显式全图或覆盖。预览渲染真实候选，应用直接提交已展示结果；参数变化使旧候选失效，空主体不能误清整图，取消或过期结果不写入。支持原子撤销、重做和保存重开。新图片导入仍保留原流程，不把本次称为所有导入链路迁移完成。
4. **大图编解码**：移除字符串 iterable 到 TypedArray 的大量中间分配，改为预分配数组和索引循环；8 位编码读取当前子视图，16 位显式小端写入。保留严格 Base64 规范校验、字节长度与数据类型校验，没有靠跳过检查提速。
5. **计算资源调度**：颜色识别及明确主体蒙版的合并走 CPU，不关闭常驻 GPU 模型。需要真实预测的识别和导入保持 GPU 交接、取消及资源占用规则。提前拒绝会被 JSON 隐式转换成 null 的非法蒙版，普通对象蒙版继续由 Python 严格解码验证。

## 性能证据

独立审查代理对实际 codec 源码转译产物做同环境单次对照：2048×2048 RGBA 完整解码由约 2,134 ms 降至 85 ms，进程峰值 RSS 由约 628 MiB 降至 210 MiB。基准运行在本机 Node 20.19.5，低于 package 声明的 Node >=22.12.0，因此这里只作同环境热点对照，不是 Electron 生产性能承诺或整条识别链提速倍数。

原有 2048 栅格功能测试曾在并行运行时耗时 7.2 秒、单独重跑全套时耗时 5.7 秒，触发 5 秒限制；优化后全套中的该用例约 1.42 秒。没有放宽测试超时。

独立边界检查覆盖 18 种空数组、子视图、分块边界与独立内存情形，以及 15,360 种非规范 Base64 尾位和 8 种畸形输入，均保持严格拒绝或无损往返。

毫米倒角的单台面 512/1024/2048 测量约 0.031/0.108/0.436 秒。大量嵌套台面仍会重复处理包围盒，非方像素复杂图案的最坏开销留在 RA16；不能将单台面结果宣传为所有图案上限。
