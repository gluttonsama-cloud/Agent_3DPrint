## B 端接回方法

先保存 B 电脑上的未提交修改，再获取整合分支；不重置或强推原分支。

```powershell
git fetch origin
git switch -c cys/relief-d1-integration --track origin/cys/relief-d1-integration
cd relief-studio
npm.cmd ci
python -m venv .venv
.venv/Scripts/python -m pip install -r engine/requirements.txt
npm.cmd run build
npx.cmd electron .
```

已有可用 `.venv` 时保留并复用，不必重新创建。纯 D1 模拟工作台可用 `npx.cmd electron . --d1`。
开发版只需重新构建并重启；原先已安装的客户端不会自动变成此次代码。
