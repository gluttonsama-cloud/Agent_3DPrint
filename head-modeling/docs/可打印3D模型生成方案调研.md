# 可打印 3D 模型生成方案调研

调研日期：2026-10-01。范围：现有照片转人像/头部建模产品，同时比较公仔和通用摆件。
方法：核对本地实现、供应商官方 API 文档、计费页和产品公告；本轮没有调用付费 API、上传人物照片或打印样件。
本文的推荐顺序是测试优先级，不是已验证的质量排名。厂商的 print-ready 宣传不作为本项目打印验收。

## 1. 结论

建议将方案升级为“生成模型 + 打印前处理 + 切片验收”，先测试候选，再确定默认供应商。

- 真人头部/半身像：优先试 Hi3D Portrait v2.1，原因是公开 API 提供专用人像模型和多视图输入。
- 通用打印与公仔：优先试 Meshy，原因是已公开生成、检测、修复和多色打印接口；公仔另有 Figure API。
- Tripo：作为通用生成和接入成本的主要对照，公开文档有国内站与 v3 API。
- 混元 HY-3D-3.1：保留作现有供应商升级对照，不凭“旧项目”三个字直接淘汰。
- Rodin：作为高质量资产候选，第一轮不优先承担较高的 API 订阅门槛。
- TRELLIS.2：作为未来自部署研究候选，不作为这轮最快交付路径。

这些选择分别依据下文官方文档；人像相似度、打印成功率和人工修模时间仍需同图测试。

## 2. 当前项目真正需要升级的部分

本地 `services/backend/src/services/hunyuan3d.js` 已指定 `Model: '3.0'`，调用 `SubmitHunyuanTo3DProJob`。
当前项目说明还记录了内存任务存储、Replicate 自动降级未实现等限制。
因此方案落后主要体现在交付流程：现有链路以生成、预览和下载为终点，尚未建立可打印性检查与修复验收。

## 5. “可打印”要核查到哪一步

Meshy 检测 API 的公开指标包括封闭性、体积、非流形边、退化面与孔洞，定位为 FDM 可打印性分析。
其中没有足以替代完整壁厚、支撑或树脂排液设计的公开指标；不应把 healthy 状态展示成“任何打印机都能成功”。
[检测接口](https://docs.meshy.ai/en/api/analyze-printability)

修复 API 接受外部模型，因而可以考虑“Hi3D 生成 + Meshy 修复”的组合。但该接口明确说明修复会移除纹理，输出格式与输入一致；这条组合仍需实测。
[修复接口](https://docs.meshy.ai/en/api/repair-printability)

建议验收分四层：

1. **形状正确**：相似度、比例、完整轮廓；关闭纹理再看，避免把颜色和阴影误当几何细节。
2. **网格合格**：封闭、正体积、没有不可接受的非流形与悬空碎片。
3. **切片可行**：按实际高度检查薄弱连接、底座、支撑、方向和切片预览；树脂流程另外检查中空和排液。
4. **样件通过**：实际打印后再确认面部辨识度、细节保留、拆支撑损伤与稳定性。

前三层只能给出打印候选，第四层才能说明该尺寸、材料和工艺下的样件通过。
打印过程仍交给切片器；这不需要恢复已经封存的设备、订单和库存管理。
厂商自己的工作流也要求生成后检查、修复、缩放、切片和打印。[Meshy 打印指南](https://docs.meshy.ai/en/webapp/guides/use-cases/3d-printing)

## 6. 建议的新流程

单色打印或打印后上色：

```text
照片与目标高度 → 人像/通用生成 → 白模预览 → 检查与修复
              → 确认尺寸、底座和薄弱部位 → 导出 STL → 切片验收
```

多色打印：

```text
生成形状与颜色 → 检查几何 → 必要时修复及重新贴图
              → 确认有限色映射 → 输出适配切片器的 3MF → 切片验收
```

不能简单把普通 GLB 转成 STL 就宣称打印就绪；也不能把普通纹理 3MF 与多材料分配完成的 3MF 混为一谈。
Meshy 多色接口提供至多 16 色的调色板，仍需在目标切片器检查颜色和材料映射。[多色打印 API](https://docs.meshy.ai/en/api/multi-color-print)

若目标是卡通公仔，可以单独测试 Meshy Figure：人物照片先产生 Q 版概念图，再生成模型。
这适合用户先确认风格，但不等同于真人头部忠实重建。[Figure API](https://docs.meshy.ai/en/api/creative-lab-figure)

Hi3D 的 Portrait v2.1 接口文档列出不支持 request_type=2 的分阶段纹理生成。
因此不能预设所有供应商都支持“白模确认后，原地补纹理”；单色白模和彩色一次生成应分别设计。
[参数和错误码说明](https://docs.hi3d.ai/en/api/api-reference/list/create-task)

## 7. 建议的小样对比

第一轮建议选择 6 组有使用授权的同一人物多角度照片，覆盖普通短发、长发、眼镜、胡须、复杂发型和一个卡通目标。
真人重建使用真实多角度照片；AI 补出来的侧面只作为生成假设，不当成真实采集证据。

主对比：Hi3D Portrait、Meshy、Tripo，每组各生成两次，共 36 次。混元 3.1 可追加同组对照。
先做几何与切片筛选，随后只打印排名靠前的候选，避免把所有生成结果都打印一遍。
这是建议试验规模，未执行，也未形成支出。

记录：输入与参数、生成失败率、耗时、实际扣费、去纹理后的相似度、修复前后几何变化、人工处理分钟数、切片错误、样件结果。
建议主指标按相似度、可打印性、人工修整量排序；成本与延迟用于接近效果下的决策。

## 8. 当前决策状态

本轮完成文档调研与现有代码核对，未更换供应商或修改生成代码。
在用户明确主要产物、打印工艺及完成小样对照前，Hi3D Portrait 与 Meshy 是优先验证对象，不能宣布最终胜出方案。
下一步先确认“像本人的真人像”还是“照片转卡通公仔”，两者的优化目标和最佳流程不同。
