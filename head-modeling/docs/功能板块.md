# 当前功能板块

| 板块 | 主要入口 | 下一步优化重点 |
| --- | --- | --- |
| 拍摄与上传 | Guide、Upload、uploadService、routes/upload | 照片质量、输入约束、上传重试与清晰提示 |
| 图像预处理 | AnimePreview、animeFilterService、backgroundRemoval、local-gpu-service | 抠图质量、动漫化效果、本地与云端服务边界 |
| 3D 生成 | Processing、hunyuan3d、hybridScheduler、taskStore、routes/status | 任务持久化、恢复与取消、失败分类、生成质量 |
| 预览与交付 | Preview、routes/download、qiniu | 真实模型信息、加载异常、纹理、格式与下载 |
| 基础设施 | app.js、middleware、health、Swagger、deploy、scripts | 可复现安装、配置、错误与日志、测试及部署 |

封存板块：报价订单支付、订单履约、设备打印、材料库存、AI 决策调度、运营可视化。
管理端整体封存，因为目前页面全部属于这些板块。
生成服务选择（hybridScheduler）属于 3D 生成，不属于封存的业务 Agent 调度。

优化先从“拍摄上传 → 生成 → 预览下载”端到端主链开始。
每块区分已有源码、演示数据、本地验证与真实外部服务验证。
