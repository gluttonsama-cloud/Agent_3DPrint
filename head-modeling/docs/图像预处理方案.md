# 图像预处理方案与实施步骤

用户已确认：真人还原优先，采用基础修正、可选抠图、手动裁剪和处理前后预览。

## 输入、输出与边界

- 输入为最多四张 JPEG、PNG、WebP 照片，保留原图与视角；照片选择不触发生成。
- 浏览器按图像方向解码，允许手动旋转；矩形裁剪采用源图坐标，等比缩放，最长边不超过 2048，不放大小图。
- File 与 Base64 经过相同处理；单图输出上限 3 MB，JPEG 输出显式填白，避免透明背景变黑。
- 抠图为独立的用户操作，调用现有 PicWish 配置；返回内联 PNG 供预览，不依赖七牛云。未配置或失败时展示错误，保留当前图像。
- 页面保存原图、处理基图、裁剪参数和最终预览。任何修改后旧预览失效；处理完成前禁止提交，返回重选保留原图。
- 生成接口仍使用 uploadPhotos；生成 provider 和后端 upload/status 等文件交由另一 agent 维护。本轮只替换上传前的图像准备逻辑。
- 不执行付费生成或真实抠图。真实照片效果、Android 真机和打印质量需要后续验收。

## 验收

1. 原始长宽比例不被拉伸；带方向标记的手机照片正确显示，手动旋转可恢复。
2. 裁剪保留区域与预览一致；重置恢复原图，透明图输出白底。
3. 未解码、超限或无法读取的文件有中文错误；低分辨率仅提醒，不虚构清晰度评分。
4. 连续修改或离开页面后旧异步结果不能覆盖最新结果；抠图失败可重试或继续使用原图。
5. 提交使用屏幕上已确认的最新预览，单张使用 single，多张使用 multiview，保留照片顺序及视角字段。

## 裁剪交互修订

根据用户确认，取消四边百分比滑块，使用拖拽裁剪框，框外压暗。
支持移动选区、角点/边缘缩放、自由/正方形/3:4 比例和应用/取消。
编辑器展示旋转后的完整处理基图，重复进入可扩大选区；预处理服务仍以百分比映射源图坐标。
移动端采用单张大图和原图对照切换。内部边距校验改为有效非空矩形，不再限制每边最多 45%。
